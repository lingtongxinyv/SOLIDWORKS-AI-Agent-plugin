SwAiAssistant — SolidWorks AI 辅助建模助手
版本：0.2.0（M2 发布版）
适用：SolidWorks 2025 / 2026，64 位 Windows 10 / 11

------------------------------------------------------------
一、安装
------------------------------------------------------------
1. 关闭 SolidWorks。
2. 右键点击「安装.bat」→「以管理员身份运行」。
3. 看到“安装完成”后启动 SolidWorks。
4. 功能区出现「AI 助手」标签页，右侧自动打开任务面板。

说明：安装脚本使用系统自带的 64 位 RegAsm 注册 COM 组件，
并写入 SolidWorks 插件启动项，不向 GAC 写入任何文件。
出现 “RA0000 /codebase” 的警告属正常现象（程序集未强名称签名）。

------------------------------------------------------------
二、卸载
------------------------------------------------------------
右键「卸载.bat」→「以管理员身份运行」，重启 SolidWorks 即可。
配置与日志保留在 %AppData%\SwAiAssistant\，如需彻底清除请手动删除。

------------------------------------------------------------
三、首次使用：配置 AI 模型（必做）
------------------------------------------------------------
插件采用“混合模式 AI 大脑”：默认云端 API，可一键切换本机 Ollama。

【云端模型（推荐，效果最好）】
1. 打开右侧任务面板 →「设置」页 →「添加模型」。
2. 填写：
   - 名称：任意（如 “DeepSeek”）
   - BaseUrl：服务商的 OpenAI 兼容端点
     · DeepSeek：https://api.deepseek.com/v1
     · 阿里百炼：https://dashscope.aliyuncs.com/compatible-mode/v1
     · Moonshot：https://api.moonshot.cn/v1
   - API Key：到对应服务商官网申请（Key 只保存在本机
     %AppData%\SwAiAssistant\ 配置中，Windows DPAPI 加密存储，不会上传）
   - 模型名：如 deepseek-chat / qwen-plus / moonshot-v1-8k
3. 点「探测能力」确认可用；有视觉模型（如 qwen-vl-max）时勾选视觉能力，
   可获得建模后多视角截图复核。

【本机 Ollama（离线/隐私场景）】
1. 安装 Ollama（https://ollama.com）并保持服务运行。
2. 面板「设置」页底部 Ollama 区：点「刷新」确认服务正常；
   无模型时点「拉取推荐模型」一键下载（进度可见、可取消）。
3. 云端全部不可用时，插件会自动降级到本机 Ollama 并提示
   “已切换离线模式”。

------------------------------------------------------------
四、当前版本功能（0.2.0 / M2）
------------------------------------------------------------
- 自然语言建模：对话描述零件 → AI 生成 JSON 特征树 → 计划卡片
  可改数值 → 确定性执行（AI 只出 JSON 参数，插件本身不执行任何模型生成代码）
- 草图实体：中心/角点矩形、圆、圆弧、直槽口、正多边形、自由轮廓（折线）、
  中心线（旋转轴）；所有几何按给定坐标精确创建。
  注意：本版本不自动施加草图几何约束与尺寸标注（计划中即使声明也会
  跳过并在执行报告中提示），如需请在 SolidWorks 中手工补充。
- 特征：拉伸凸台/切除（含贯穿）、旋转凸台/切除、圆角、倒角、
  孔（优先异型孔向导，失败时自动降级为草图圆切除；支持沉孔）、
  线性/圆周阵列、镜像、拔模、抽壳、GB 材料赋值。
  筋板（rib）为实验能力，部分草图策略下可能失败，建议用小矩形凸台替代。
- 螺纹孔：计划支持 threaded/threadSpec 声明，本版本只按攻丝底孔直径
  创建光孔，不自动攻丝、不添加螺纹装饰线，执行报告会明确提示需手工补螺纹。
- 对话修改（针对活动零件）：改尺寸（孔径/板厚等，如「把孔改成 φ8」）、
  追加特征、删除 AI 创建的特征；每次修改前自动记快照可回滚。
- 确定性数据问答（不经大模型、不臆测）：质量、体积、包围盒、孔数/孔径、
  特征清单（如「这个零件多重？」「有几个孔？」）。
- GB 材料库：16 项常用国标材料，按名称/别名匹配自动猜材，
  「材料」页可手动改赋，改后质量按新密度真实回读。
- 强校验闭环：执行前理论预算 vs 执行后真实回读，比较体积与包围盒边长
  （孔数不一致给警告），偏差超阈值（默认 5%，设置页可调）
  弹「采纳 / 回滚 / 让 AI 修复」三选项；选「让 AI 修复」会把
  SolidWorks 报错回传模型自动改计划重试（最多 2 次）。
- 视觉复核（可选）：配置视觉模型后，建模完成自动多视角截图送审。
- 快照与一键回滚：每次 AI 执行/修改前自动记快照；「快照」页可回滚到
  任一历史状态（回滚前自动再记快照，可反悔）。
- 反建辅助（实验）：DXF 板类轮廓反建、图片/PDF 草图反建；
  工程图导出与装配体辅助为基础能力，复杂图纸/装配请人工复核。
- 极速模式：计划不弹确认直接执行（面板快捷开关）。
- 执行取消：执行中点「取消」按钮即时中止（残留特征可快照回滚）。

------------------------------------------------------------
五、排障（FAQ）
------------------------------------------------------------
- 插件未出现：确认用管理员运行过安装.bat；在功能区标签条右键
  菜单中检查「AI 助手」是否勾选；查看 %AppData%\SwAiAssistant\logs\。
- 注册提示找不到 DLL：确认解压后的所有文件在同一文件夹内
  （SwAiAssistant.AddIn.dll 与 SolidWorks.Interop.*.dll 必须在一起）。
- “没有可用模型”：到设置页添加云端模型，或启动本机 Ollama。
- “SolidWorks 正忙”：先关闭 SolidWorks 里所有弹出对话框再重试。
- 建模偏差超限报警：选「让 AI 修复」会把错误原因回传给 AI 自动修正。
- 反馈问题：面板「日志」页 →「导出日志 ZIP」，随问题描述一并提交。

------------------------------------------------------------
六、已知限制与后续计划
------------------------------------------------------------
本版本（0.2.0）已知不支持/不自动完成：
- 草图几何约束与尺寸标注的自动施加（坐标精确建模，标注可后补）；
- 螺纹攻丝与螺纹装饰线（螺纹孔按攻丝底孔光孔创建）；
- 筋板为实验能力，复杂草图可能失败；
- 含圆弧轮廓的理论体积为近似预算，强校验会标注「含估算」；
- 真实复杂工程图（多视图标注齐全的生产图纸）的反建未做代表性验证。

后续计划：约束/标注自动施加与螺纹孔向导实装、筋板策略攻关、
复杂工程图反建样本扩充、装配体干涉与配合辅助增强。
