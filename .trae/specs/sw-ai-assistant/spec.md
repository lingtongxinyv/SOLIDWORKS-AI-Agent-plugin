# SwAiAssistant（SolidWorks AI 辅助建模助手）- 产品需求文档

## Overview

- **Summary**：一个原生嵌入 SolidWorks 2025/2026 的 AI 辅助建模插件。用户通过中文自然语言对话完成板类/支座类零件建模、多轮修改与问答；插件以"JSON 特征树 → 确定性执行 → 真实回读校验"的闭环保证建模可靠性。后续扩展自动出工程图、装配体辅助、DXF/DWG 与图片图纸反建。
- **Purpose**：让不熟悉 SolidWorks 复杂操作的用户用自然语言完成尽可能多的 CAD 任务，同时保证结果可控、可校验、可回退。
- **Target Users**：已安装 SolidWorks 2025/2026 的机械设计人员、学生、爱好者；主要单机使用，兼顾离线隐私场景。

## Goals

1. 原生插件形态：SW 功能区出现"AI 助手"标签页 + 右侧 WPF 任务面板，全程中文界面。
2. 绿色独立：目标电脑只需已装 SolidWorks，不安装 Python 或任何额外运行时；便携 ZIP + 一键安装/卸载脚本。
3. 混合 AI 大脑：用户可添加任意数量的云端模型（自定义名称 / Base URL / API Key / 模型名）与本地 Ollama；程序自动探测模型能力并自动分工；云端全部失败时自动降级 Ollama 并在界面提示离线模式。
4. 核心建模：板类/支座类零件自然语言单件建模，覆盖约定的 19 项草图/特征操作；默认"先出计划、确认后执行"，可切换极速模式。
5. 对话式修改与问答：通过改驱动尺寸/编辑特征实现"把四个孔改成 φ8""厚度加到 12"等修改而非重建；可问答质量、包围盒等真实数据。
6. 强校验闭环：建前理论预算（体积/包围盒/孔数）→ 确定性执行 → 真实回读 → 截图视觉复核 → 偏差超阈值报警；失败携带 SW 报错自动重试（≤2 次）。
7. 安全可回退：每次 AI 执行前自动快照，面板一键回滚到任一历史版本。
8. 能力扩展（在核心闭环做稳之后依次交付）：一键 GB 第一角三视图工程图、装配体辅助（插入/配合/干涉检查）、DXF/DWG 矢量图纸反建（简单件）、图片/PDF 图纸半自动反建。

## Non-Goals

- 不做在未安装 SolidWorks 的电脑上建模（无 SW 时无法产出/操作原生 `.sldprt`；不引入 OCCT 降级内核）。
- 不做 Mac/Linux 支持。
- 不让 LLM 直接生成或执行代码（绝不 `exec`/编译运行模型产出的代码）。
- 不做版本分支式 Git 化模型管理（只线性快照回滚，不做分支对比）。
- 第一周期不做 GB 标准件库（螺钉/轴承/型材参数化库）、运动仿真、曲面/焊件/模具等高级专业模块。
- 不承诺图片/PDF 图纸反建的全自动准确率：该功能强制"AI 识别 → 计划 → 人工确认 → 建模"半自动路径，并在界面明确标注实验性质。
- 不做移动端/Web 端。

## Background & Context

- 前期完成 GitHub 调研（见 `c:\Users\16650\Desktop\调研SolidWorks AI插件GitHub仓库.md`），关键结论：
  - SolidWorks 仅暴露 Windows COM API（`SldWorks.Application`），这是官方唯一自动化途径；COM 调用必须在 STA 线程。
  - 范式三代演进已收敛：LLM 直接生成代码（已证伪，Vulcan 血泪教训）→ JSON 特征树确定性执行（MVP，本项目核心）→ 中性 IR + 编译器（远期）。
  - 必须有截图 + 质量属性回读的反馈闭环，否则是"盲建模"（SolidPilot 客观验收 ΔV≤1% 为 verified）。
  - 可借鉴 MIT 仓库（solidworks-automation-skill、just1step/solidworks-mcp、HarrierPigeon 等）；AGPL/GPL 仓库（SolidPilot、Vulcan、swex）只学架构不抄代码。
- 经 18 轮问答确认的全部需求决策见调研文档"需求确认总表"；2026-09-25 用户最终裁定：**功能范围尽可能多**——核心单件建模闭环优先做稳，工程图/装配/两类图纸反建均纳入本开发周期，按里程碑依次交付。
- 开发机已核实：SolidWorks 2026（COM ProgID `SldWorks.Application.34`，安装于 `D:\Program Files\SOLIDWORKS Corp\SOLIDWORKS (2)`，Interop 在 `api\redist`）、.NET SDK 10.0.300、MSBuild（VS Build Tools 2026）、.NET Framework 4.8 目标包均就绪；Ollama 0.34.1 已装但服务异常待修。
- 兼容 SW 2025：仅使用长期稳定 API，针对版本间签名差异的方法（如 FeatureExtrusion2/3）做运行时兼容。

## Functional Requirements

### 插件基础设施
- **FR-1**：插件以 C# .NET Framework 4.8 / x64 COM Add-in 实现，SW 启动后功能区出现"AI 助手"命令组标签页，含右侧任务面板宿主；任务面板为 WPF 原生控件（不依赖 WebView2 等额外运行时），包含：对话区、计划卡片、材料区、快照列表、模型设置页。
- **FR-2**：提供便携 ZIP 分发：解压后右键管理员运行 `安装.bat` 自动完成 COM 注册与 SolidWorks Addins 注册表双写；`卸载.bat` 完整清除；安装脚本自检管理员权限并自动定位 64 位 RegAsm。
- **FR-3**：所有配置写入 `%AppData%\SwAiAssistant\`；API Key 使用 Windows DPAPI 加密存储，绝不硬编码；日志按日写入 `%AppData%\SwAiAssistant\logs\`。
- **FR-4**：所有 COM 交互集中在单一 Cad 层并封送到 STA 线程执行；AI/Planner 等其他层不直接触碰 COM；SW API 异常被捕获、中文化展示并记录日志，不得导致 SolidWorks 崩溃或卡死。

### AI 层
- **FR-5**：模型设置页支持增/删/改任意数量的模型配置（名称、Base URL、API Key、模型名、协议类型 OpenAI 兼容/Ollama 自动识别），提供"连通测试"按钮。
- **FR-6**：能力自动探测：通过 `/v1/models`、`/api/tags` 与视觉模型名特征库自动画像每个模型（文本/视觉、上下文长度、本地或云端），探测结果在 UI 展示；探测失败时允许用户手动勾选能力。
- **FR-7**：任务自动调度：规划建模、视觉复核、数值复核、离线备用等任务由调度器按能力画像自动分配，用户无需指定"用哪个模型干什么"；云端模型全部不可用时（断网/Key 失效/超时）自动降级到本地 Ollama 重试一次，对话区提示"已切换离线模式"。
- **FR-8**：提供 Ollama 一键修复（服务异常时尝试恢复）与一键拉取推荐模型（一个文本模型 + 一个视觉模型）按钮，展示拉取进度；用户也可只填配置不下载。
- **FR-9**：零 Key 可用：用户未配置任何云端模型时，插件仍可通过本地 Ollama 完成纯文本建模全流程（视觉能力自动降级为纯数据校验）。

### 规划与执行
- **FR-10**：Planner 将自然语言（含多轮对话上下文、当前模型状态）转换为受 Schema 约束的 JSON 特征树；领域系统提示词编码基准面坐标系映射（前视 X-Y / 上视 X-Z / 右视 Y-Z）、内部单位米、特征顺序约束；Schema 校验失败的 JSON 不得进入执行。
- **FR-11**：文档策略：当前无打开的零件文档时自动新建零件；已有打开零件时弹出询问"在当前零件继续 / 新建零件"；对话修改与问答始终针对当前活动文档。
- **FR-12**：默认计划模式：AI 先在计划卡片列出有序建模步骤与参数，用户可直接修改参数，点"执行"后才操作 SW；可在设置切换极速模式（立即执行，聊天区显示逐步进度）。
- **FR-13**：19 项建模操作全覆盖：
  - 草图 7 项：矩形、圆、槽口/长圆孔、多边形、直线/圆弧自由轮廓、尺寸驱动标注、几何约束（重合/同心/水平竖直等）；
  - 特征 12 项：拉伸凸台、拉伸切除、旋转凸台/切除、圆角、倒角、简单直孔/异型孔向导（螺纹孔）、线性阵列、圆周阵列、镜像、筋板、拔模、抽壳。
  - 异型孔向导遇 API 阻力时降级为"草图圆 + 拉伸切除"实现通孔/沉孔，并在计划中如实标注。
- **FR-14**：对话式修改：维护 AI 特征注册表（AI 创建的特征统一命名前缀 + 尺寸全名映射），支持改尺寸值、改特征参数、追加/删除特征（如"四角孔改 φ8 并加沉孔"），不整体重建；问答类请求回读活动文档真实数据（质量、体积、包围盒、特征清单、孔数）后用自然语言回答。
- **FR-15**：材料：AI 根据描述自动猜测材料；提供常用 GB 材料库下拉（Q235、45 钢、6061 铝合金、304 不锈钢等，含密度表）；用户可随时手动改，质量属性按真实密度计算。
- **FR-16**：快照与回滚：每次 AI 执行前自动记录快照（执行前特征清单与尺寸值）；快照列表支持一键回滚（删除带 AI 标记的特征并恢复尺寸值），回滚本身也先记录快照。
- **FR-17**：强校验闭环：执行前按特征树预算理论体积、包围盒尺寸、孔数；执行后回读真实值对比；自动旋转视角截图送视觉模型审查（纯文本模型时跳过视觉仅做数值校验）；任一偏差 >5%（体积/包围盒）或视觉判定异常时，在对话区明确报警并附偏差数据，由用户确认采纳/回滚/让 AI 修复；执行失败时把 SW 报错文本反馈给模型自动修正重试，最多 2 次。

### 扩展能力（核心闭环验收后依次交付）
- **FR-18（工程图）**：一键由当前零件生成 GB 第一角三视图工程图（前视/上视/左视），自动插入模型尺寸并导出 PDF；提供带简易国标标题栏（零件名/材料/比例/日期/制图）的图纸模板。
- **FR-19（装配体）**：可将已保存零件插入新装配体或当前装配体；执行自动配合（重合、同轴、距离）；一键干涉检查并用中文列出干涉零件与体积；支持对话式"把 A 装到 B 的顶面"这类指令的计划确认执行。
- **FR-20（DXF/DWG 反建）**：导入矢量图纸文件，解析图层/轮廓/标注，输出结构化分析（视图、闭合轮廓链、尺寸真值），由 AI 在规则集下生成特征树计划，**强制人工确认**后建模；以简单平板/钣金/板类件为验证对象。
- **FR-21（图片/PDF 反建）**：用视觉模型识别图片/扫描件/PDF 截图中的视图与尺寸，生成特征树计划；**强制人工确认节点**，未确认不得建模；界面标注"实验功能，尺寸请逐项核对"。

## Non-Functional Requirements

- **NFR-1 独立部署**：发布物仅含插件 DLL/资源/脚本与第三方托管 DLL（随插件目录存放，不入 GAC）；目标机无需安装 Python、Node、WebView2 或其他运行时（.NET Framework 4.8 随 Windows 10/11 提供）。
- **NFR-2 稳定性**：连续 20 次以上建模对话不崩溃、不残留僵尸 SW 进程；所有后台操作可取消；SW 关闭时插件正常断开。
- **NFR-3 可观测**：关键链路（模型调用、特征树、每步 COM 调用、回读值、校验结果）均有日志，日志含时间戳与级别；提供"打开日志目录"入口。
- **NFR-4 性能**：单次规划云端请求超时可配置（默认 60s）；面板任何网络请求不得阻塞 SW UI 线程；截图单张压缩到合理 token 体积。
- **NFR-5 安全**：Key 仅 DPAPI 加密存本机；默认不向除用户配置端点之外的任何地址发送数据；截图/图纸仅在用户使用对应云端模型时外传。
- **NFR-6 可维护性**：Cad 层按"草图/特征/查询/工程图/装配/反建"分模块；每个 COM 操作有 XML 文档注释记录所用 API 与 SW 版本注意事项；解决方案可由一条命令 Release 构建并打 ZIP 包。

## Constraints

- **Technical**：
  - C# / .NET Framework 4.8 / x64 / WPF；唯一自动化通道为 SolidWorks COM（`SldWorks.Application`），全程 STA。
  - 目标 SW 版本 2025/2026；以 SW2026 Interop（`D:\Program Files\SOLIDWORKS Corp\SOLIDWORKS (2)\api\redist`）为开发引用，仅使用长期稳定 API。
  - 构建机：.NET SDK 10 + MSBuild（VS Build Tools 2026）；net48 目标包已确认存在。
  - 第三方库仅限 MIT/BSD/Apache 等宽松许可（如 Newtonsoft.Json、netDxf）；AGPL/GPL 代码不得引入。
  - COM 注册必须双层：RegAsm `/codebase`（CLSID）+ SolidWorks Addins 注册表键（含 Title/Description/启动加载）。
- **Business**：
  - 界面与文档全部中文。
  - 项目代号 SwAiAssistant（未改名即默认）。
- **Dependencies**：
  - 云端模型服务由用户自备 API Key 与端点；本地路径依赖 Ollama（插件提供一键拉取/修复，但不内嵌模型权重）。
  - 真机 GUI 验证由用户在 SolidWorks 中按测试清单点击确认；开发方可用 COM 自动化控制台在后台驱动 SW 完成建模类集成验证（截图类除外）。

## Assumptions

- 用户始终在装有已激活 SolidWorks 2025/2026 的 64 位 Windows 10/11 上使用。
- 用户愿意在安装时授予一次管理员权限以完成 COM 注册。
- 建模对象以板类/支座类机加工零件为主；复杂曲面、多实体、焊件等不在成功率承诺内。
- 工程图标题栏使用插件自带简易模板；企业定制图框为后续需求。
- 体积/包围盒校验阈值固定 5%（后续可在设置中调整）。
- 推荐本地模型为 14B 级文本模型与同级视觉模型；用户硬件不足以运行时可自行换小模型，插件不硬性拦截。

## Acceptance Criteria

### AC-1：插件注册加载与界面呈现
- **Type**: `rule`
- **Given**：一台装有 SolidWorks 2025 或 2026、未装任何开发环境的 64 位 Windows
- **When**：解压便携 ZIP，管理员运行安装.bat 后启动 SolidWorks
- **Then**：功能区出现"AI 助手"标签页，点击可打开右侧 WPF 任务面板（对话区/计划卡片/材料/快照/设置五个区域齐全），运行卸载.bat 后重启 SW，标签页与注册项消失
- **Pass Condition**：用户在真实 SW2026 按测试清单确认上述全部现象；注册表检查项前后对比干净
- **Evidence**：安装/卸载控制台输出、注册表键截图、SW 界面截图、安装日志

### AC-2：零运行时依赖的绿色部署
- **Type**: `rule`
- **Given**：同 AC-1 的干净环境（无 Python、无 WebView2、无额外运行时）
- **When**：仅执行安装.bat
- **Then**：插件全部功能（除联网调用外）可运行，插件目录外不写入 Program Files、不注册 GAC（CLSID/Addins 注册表项除外）
- **Pass Condition**：目录清单与注册表写入清单符合发布说明；全过程无任何运行时下载/安装提示
- **Evidence**：ZIP 文件清单、安装日志、文件系统/注册表核查记录

### AC-3：模型配置与密钥安全
- **Type**: `rule`
- **Given**：任务面板设置页
- **When**：添加多个模型（云端 OpenAI 兼容端点 + Ollama），执行连通测试，关闭重开面板
- **Then**：配置持久化且 API Key 在配置文件中为 DPAPI 密文、界面仅掩码显示；连通测试正确报告成功/失败及原因
- **Pass Condition**：直接打开配置文件找不到明文 Key；增删改与连通测试结果均符合实际
- **Evidence**：加密后的配置文件片段、连通测试截图

### AC-4：能力自动探测与任务自动调度
- **Type**: `rule`
- **Given**：已配置 ≥1 个文本云端模型、1 个视觉云端模型、1 个本地 Ollama 文本模型
- **When**：分别发起建模规划、截图复核、断网后再建模
- **Then**：UI 显示每个模型被自动探测出的能力标签；规划自动走云端文本模型、截图复核自动走视觉模型；断网/云端报错后自动用 Ollama 重试并提示"已切换离线模式"
- **Pass Condition**：日志中三次任务实际命中的模型与自动路由规则一致；断网场景建模仍能完成
- **Evidence**：能力标签截图、调度日志（含模型选择与降级记录）

### AC-5：JSON 特征树红线
- **Type**: `rule`
- **Given**：任意模型返回的内容（含故意诱导其输出代码的用例）
- **When**：Planner 处理模型响应
- **Then**：仅接受符合 Schema 的 JSON 特征树；返回代码或非法 JSON 时进入纠正重试，任何路径都不编译/执行模型产出的代码
- **Pass Condition**：代码审计确认无进程内代码执行 API（无 CSharpCodeProvider/AddScript/exec 类调用）；诱导用例被安全拒绝并要求重出 JSON
- **Evidence**：源码审计记录、诱导用例对话与日志

### AC-6：文档策略与双执行模式
- **Type**: `rule`
- **Given/When/Then**：
  1. 无打开零件时发建模指令 → 自动新建零件并开始；
  2. 有打开零件时发指令 → 弹出"当前继续/新建"选择；
  3. 计划模式下列出可编辑的步骤参数，未点执行前 SW 不发生任何建模变化，改参数后按新参数执行；
  4. 极速模式下发指令后立即执行并逐步显示进度。
- **Pass Condition**：4 个子场景在真机各验证通过
- **Evidence**：面板截图 + SW 模型树截图 + 日志时序

### AC-7：19 项建模操作齐备且真实生效
- **Type**: `rule`
- **Given**：覆盖 19 项操作的测试指令集（每项至少 1 个独立指令 + 1 个组合件指令）
- **When**：逐项计划确认执行
